# Insurance Management System

Webová aplikace pro správu pojištěných osob a jejich pojištění vytvořená v PHP s využitím MVC architektury.

## Použité technologie

- PHP
- MySQL
- Bootstrap 5
- HTML/CSS
- MVC architektura

## Funkce

- Správa pojištěných osob
    - vytvoření
    - editace
    - odstranění
    - výpis detail

- Správa pojištění
    - přidání pojištění k uživateli
    - editace pojištění
    - odstranění pojištění
